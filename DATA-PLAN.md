## Long-term data behavior
- **Refresh policy**: No external refresh; data changes only through user actions in the dashboard. No cron/refresh triggers.
- **Growth**: Trades, wallet transactions, duels, signals, and mining logs append over time; positions upsert per symbol. Lists return newest-first with sensible caps.
- **Ordering**: Trades/txns/logs newest first; positions by market value descending; duels by status then recency.
- **Time semantics**: created_at stored as epoch-ms instants, rendered viewer-local; mining log dates are user-entered calendar dates.
